## 重复验证

在 `desktop/` 中：

```powershell
npm ci
npm test
npm run build
cd src-tauri
../tools/test-native.ps1
cargo check --release
```

原生可视测试为隔离fixture，默认忽略；单独运行前需嵌入 `test-fixtures/windows.manifest`。使用Visual Studio的mt.exe对编译生成的测试EXE操作，不修改当前运行的客户端。需要实际网络的测试单独安排，不和普通回归一起自动执行。
