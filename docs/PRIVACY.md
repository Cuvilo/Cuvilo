# 数据与隐私说明

[返回首页](../README.md) · [使用指南](GETTING_STARTED.md)

本说明描述当前桌面客户端的数据路径，不替代所选第三方服务的隐私政策。

## 保存在本机的数据

- 个人材料、会话、文字转写、参考答案和设置保存在 `%APPDATA%/local.interview.copilot/`。
- 服务 API Key 等凭据保存在 Windows 凭据管理器，沿用 `InterviewCopilot/` 命名空间；本地存储不代表云端调用时不发送鉴权信息。
- 默认不保存原始录音。截图仅为当前提问临时使用，重新截图或结束会话后释放。
- 知识资料使用本地关键词检索、去重与片段预算，不下载 embedding 模型。

## 什么时候数据会离开电脑

| 操作 | 发送内容 | 接收方 |
| --- | --- | --- |
| 云端语音识别 | 所选音源的音频片段或音频流 | 当前语音服务 |
| 模型回答 | 问题、必要上下文及材料片段 | 当前回答模型服务 |
| 模型识图 | 选区图片和必要问题上下文 | 指定的识图模型服务 |
| 云端 OCR | 选区图片 | 当前云端 OCR 服务 |
| 本地 Windows OCR | 图片在本机识别；后续云端回答仍会发送所需文字 | Windows 本地识别能力、随后所选模型 |
| 服务检测及模型列表 | 当前填写的服务地址、凭据及必要测试请求 | 对应服务商 |
| 软件更新检查与下载 | GitHub Release 更新清单及安装包请求 | GitHub 及其分发基础设施 |

服务商可能有独立的计费、日志与数据保留政策，请使用符合自己要求的账号和服务。截图识图失败后可能使用 OCR 回退，是否上传图片取决于所选 OCR 服务。

## 备份与公开反馈

“设置 → 数据”的导出包含材料和文字记录，不包含服务配置或密钥，但备份本身仍可能包含个人信息。请保存在自己的可信位置，不要公开提交到 Issues、源码仓库或网盘分享链接。

反馈时优先使用合成问题复现，提供错误文字与必要配置类型。日志或截图应先移除密钥、账号、个人材料和对话。

## 清理与恢复

可在材料和历史页面删除相应内容。数据恢复会替换材料及面试记录，当前数据会先生成恢复副本，服务配置和密钥保持原样。需要彻底清理本地数据时，应先从托盘退出并确认备份，再自行处理应用数据目录与对应 Windows 凭据；卸载安装包不应被当作已彻底清除所有数据的证明。

安全漏洞请按[安全反馈说明](../SECURITY.md)处理。
