# 常见问题

[返回首页](README.md) · [使用指南](GETTING_STARTED.md) · [反馈问题](https://github.com/Cuvilo/Cuvilo/issues/new/choose)

## 软件收费吗？需要自己的密钥吗？

本项目按 GPL-3.0 提供源码。Cuvilo 不附送回答模型或语音服务额度，使用相应云服务需要自行配置凭据，费用和额度以服务商为准。开源许可不代表第三方 API 免费。

## 支持哪些系统？

当前发行版是 Windows x64，建议在 Windows 11 使用。macOS、Linux、Windows ARM64 暂无原生发行版。指定应用声音采集要求 Windows build 20348 或以上；较旧系统请选择系统声音。其他环境尚未完整验证。

## 下载了源码压缩包，为什么不能直接运行？

普通用户应在[最新正式版](https://github.com/Cuvilo/Cuvilo/releases/latest)下载 `Cuvilo_<版本>_x64-setup.exe`。源码包供开发者构建使用，`.sig` 和 `latest.json` 是自动更新文件。

## Windows 提示未知发布者或阻止运行怎么办？

先确认安装包来自本仓库正式 Release。可核对该版本发布说明中的 SHA-256，使用 PowerShell：

```powershell
Get-FileHash "$env:USERPROFILE\Downloads\Cuvilo_0.1.51_x64-setup.exe" -Algorithm SHA256
```

不同版本应使用对应文件名和校验值。如果来源不明、校验不一致，或者安全软件报告了具体威胁，请停止安装并反馈，不要关闭系统防护。自动更新签名用于校验更新包，不等同于 Windows 发布者代码签名。

## 为什么启动失败或窗口空白？

确认使用的是正式 x64 安装包。若提示缺少 WebView2，安装 [Microsoft 官方 Evergreen Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) 后重试。问题持续时，请反馈软件版本、Windows 版本和错误文字。

## 检测模型失败怎么办？

依次核对 API Key、Base URL、模型标识、账号地区与服务权限。密钥和模型列表可能按地区或工作空间隔离；某些套餐的专用 Key 不能用于普通按量接口。连接检测使用当前输入，修改后重新检测并保存。

“获取模型”成功只说明获取到了目录，不代表目录中每个模型都能通过 Chat Completions 作答，也不代表都支持图片输入。检查失败提示，选择对应接口支持的具体模型。

## 为什么没有会议声音或转写？

1. 确认系统或目标应用正在播放声音，且没有被静音。
2. 在首页选择正确的会议音源并运行声音检测。
3. 如果指定应用无法采集，改用系统声音排查；旧系统可能不支持进程定向采集。
4. 如果声音检测正常但没有转写，检查语音服务凭据、服务开通、账号地区、额度与网络。
5. 本人转写需要麦克风可用，并允许桌面应用访问麦克风。

系统声音与麦克风是不同音源；开启系统声音不会自动把本人的麦克风输入作为转写来源。

## 回答模型与语音识别能共用密钥吗？

取决于服务商。百炼的同一个 Key 在地区、工作空间和访问权限匹配时可用于对应模型与语音服务，两处仍需分别保存和检测。DeepSeek 等回答模型服务的 Key 不能直接作为其他平台的语音 Key。

## 语音 OpenAI 接口与实时语音有什么区别？

OpenAI 语音渠道分段上传音频至兼容 Audio Transcriptions 的接口，等待识别返回；其他实时渠道使用各自的消息、音频帧和鉴权协议。相同的 URL 形式或 API Key 字段不代表协议兼容。

## 开启“识图”后，为什么还会使用 OCR？

最多一个回答模型开启识图，且具体模型须支持图片输入。识图请求失败时，程序最多回退一次到所选 OCR 服务，再由对话模型作答；未指定识图模型时直接使用 OCR 路径。

## 本地 OCR 为什么无法识别中文？

本地 OCR 使用 Windows 自带能力，依赖已安装的识别语言和字体。请在 Windows 语言设置中检查相应语言及 OCR 组件。安装 Cuvilo 不会自动安装中文 OCR 语言包。也可以在“设置 → 服务 → 截图识别”选择可用云端服务；云端识别会上传所选图片。

默认提供的有道云端 OCR 无需自行填写密钥，但仍依赖第三方接口和网络，可能限流或不可用，不保证长期免费额度或可用性。

## 个人材料会全部发给模型吗？

我的经历用于提供个人事实；知识资料使用本地关键词评分、去重和片段预算选取相关内容。生成回答所需的文本和材料片段会随请求发送给所选模型。当前没有内置 embedding 模型或向量数据库，不应按向量检索效果理解此功能。

## 为什么生成字数与设置不完全相同？

生成字数是发给模型的目标提示，模型可能因内容、格式或服务输出限制而偏离。它不是精确的字数截断功能。

## 设置自动保存吗？关闭窗口为什么程序还在？

偏好设置会自动合并保存，服务配置使用各自的“保存”按钮。关闭主窗口的行为可在“设置 → 偏好”修改；默认收起到托盘时，程序仍在运行。完全退出请在托盘菜单选择“退出”。

## 如何更新？关闭了更新提示怎么办？

标题栏“下载更新”完成后会变为“重启更新”；托盘的新版版本号可以一键下载并安装。“设置 → 关于”始终提供更新入口。关闭标题栏的提示只隐藏同一目标版本，新版本仍会提示。面试期间和未保存编辑时会阻止安装。

没有更高正式版本时，不出现更新提示是正常情况。网络错误时可稍后重试，或前往正式 Release 下载对应安装包。

## 如何备份、换电脑或恢复？

先结束面试，再打开“设置 → 数据 → 创建备份”。导出文件包含材料、会话、转写和回答，不含服务配置及 API Key。新电脑恢复数据后需要重新配置服务。恢复会替换现有记录，注意预览并保留备份。

## 共享屏幕时窗口一定不可见吗？

“共享时隐藏 Cuvilo”使用 Windows 窗口捕获保护。实际效果取决于系统、共享软件和采集方式；不要把该选项当作对所有共享或录制方式的保证。

## 还有问题，反馈时提供什么？

通过[故障反馈表单](https://github.com/Cuvilo/Cuvilo/issues/new?template=bug_report.yml)提供软件版本、Windows 版本、服务名称、模型标识、操作步骤和错误文字。截图、日志先移除 API Key、账号、简历、录音与私人对话；不要公开整个本地数据库或备份文件。
