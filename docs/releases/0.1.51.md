# Cuvilo 0.1.51 发布说明

Cuvilo 是专为 Windows 设计的实时面试练习助手，基于 Tauri 2、Rust 与 React 构建。0.1.51 版本带来了全新的首页新手引导、识图多模态支持、答案窗口交互优化以及平滑的自动更新流程。

## 🌟 核心更新亮点

- **首页新手引导流程**：首次打开提供清晰的「连接回答模型 → 连接语音识别 → 检测会议声音」步骤卡片，小白用户开箱即用。
- **服务配置体验优化**：
  - 回答模型首选阿里云通义千问与 DeepSeek，内置官方 API Key 获取控制台快捷链接。
  - 支持多渠道配置与标准 OpenAI 兼容接口，并提供一键连接检测与连通性诊断。
- **多模态识图与智能回退**：
  - 支持为视觉模型开启「识图」开关，截屏内容直接发送给视觉大模型解析作答。
  - 模型不支持或调用失败时，自动平滑回退至选定的 OCR 提取文本后再交由对话模型作答。
- **独立答案浮窗全面优化**：
  - 窗口尺寸支持最小化紧凑阅读，半透明背景调节支持实时预览且保持文本高对比度清晰易读。
  - 代码块新增便捷一键复制按钮与高亮展示。
  - 新增「生成字数」偏好设置，灵活控制 AI 输出篇幅。
- **平滑自动更新**：
  - 标题栏与系统托盘深度集成更新通知，下载过程带进度指示，下载完成后一键重启平滑生效。
- **开源许可证**：
  - 源码全面采用 **GNU General Public License v3.0 (GPL-3.0)** 许可证。

## 💡 升级说明

- **全新安装**：下载 `Cuvilo_0.1.51_x64-setup.exe`，按安装引导完成安装即可。
